## Reserved names, migration and selection

`apps/desktop/src/themes/backend-sync.ts:44-66,105-116` reserves every built-in
and retired name; `presets.ts:468` names the retired set: default, gold,
nous-light. Android now shares this set across backend parse/apply and
appearance resolution. Reserved announcements can apply, but cannot register
or persist a converted shadow. Retired apply targets become Nous, never Classic.

Boot cache reads sanitize individual records and write the retained definitions
through the existing same-directory temporary-file replacement. Invalid records,
reserved shadows and duplicates leave disk; valid custom entries are retained.
An unwritable migration returns usable sanitized definitions without destroying
the original and retries on a later read. Corrupt/oversized envelopes remain
bounded and ignored rather than reinterpreted as valid data. Connection/profile
ownership is unchanged. Tests exercise raw old files, on-disk readback, restart,
all reserved names, invalid entries, successful and refused writes, and scope
isolation. Seeds register only; explicit changes apply once; acknowledged
duplicates cannot undo a later manual choice. Announcement identity remains
distinct from normalized appearance identity (default and nous are different
events even though both paint Nous).

## Command ownership: no invented Android interception

At the target, `apps/desktop/src/themes/use-skin-command.ts:5-15,46-57` maps
command arguments gold/hermes to classic, default/nous-light to nous, and ares
to ember. These are command aliases, not persisted/backend names. In particular,
a saved/backend gold remains retired, and a custom hermes or ares is not retired.

Android's `ChatViewModel.submitToGateway` hands the prompt to
`GatewaySessionRepository.submit`; `LiveGatewaySessionRepository` forwards it
through `prompt.submit` unchanged apart from surrounding whitespace. There is
no local `/skin` owner or Desktop hook to repoint. A regression test records
all six raw command arguments on the RPC wire. This refresh deliberately does
not intercept or rewrite them: it does **not** claim Desktop slash-alias behavior
on Android. Classic is directly available through native Appearance. Any future
local skin-command feature requires its own explicit ownership/design decision.
